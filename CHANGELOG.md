# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

## [0.3.0] - 2026-07-29

### Added
- Универсальный установщик Windows 10 1809+ для x86, x64 и Arm64.
- Обновление из интерфейса через GitHub Releases с обязательной проверкой SHA-256.
- Воспроизводимый `IndexBench` для сравнения алгоритмов обновления индекса.

### Changed
- Обход сетевых каталогов теперь потоковый и не использует активное spin-ожидание.
- Полное обновление SQLite выполняется одной атомарной транзакцией и не перезаписывает
  неизменившиеся строки.
- Снимок для сравнения хранит только нужные поля и один составной ключ вместо двух
  коллекций полных путей.

## [0.1.0] - 2026-06-18

### Added
- Поиск файлов и папок по сетевым (SMB) путям через локальный индекс SQLite.
- Режимы поиска: подстрока, маска (`*?`) и регулярные выражения.
- Фильтры по размеру, дате изменения, типу/расширениям; «только файлы»/«только папки».
- Быстрые кнопки типов: PDF, Word, Excel, Фото.
- Поиск по содержимому в текущей выборке.
- Авто-обновление индекса по интервалу.
- Портативная публикация в один self-contained `.exe`.
- Контекстное меню строки: открыть файл, открыть папку, скопировать путь.
